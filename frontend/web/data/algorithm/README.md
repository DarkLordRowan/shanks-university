# Папка Algorithms

Этот каталог содержит файлы, представляющие различные алгоритмы в формате JSON. 
Каждый файл содержит данные о соответствующем алгоритме, включая:
1. Идентификатор
2. Название
3. Описание
4. Авторов.

## Структура папки

В папке находятся следующие файлы:

- Каждый файл с расширением `.json` представляет собой описание отдельного алгоритма.
- Алгоритмы именуются по принципу: `<имя_алгоритма>_algorithm.json`.

Пример структуры одного файла алгоритма:

```json
{
    "id": "",
    "title": "",
    "subtitle": "",
    "authorIds": [""]
}
```
