# Frontend

Фронтенд для визуализации и анализа экспериментов проекта `shanks-university`.

## Скрипты
- `npm run dev` — запуск dev-сервера.
- `npm run build` — production-сборка.
- `npm run lint` — проверка ESLint.
- `npm run preview` — локальный просмотр собранного приложения.

## Важно про кодировку
Все текстовые файлы проекта должны храниться в UTF-8.
