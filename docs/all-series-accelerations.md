## Методы ускорения рядов (Transformations)

 `n` — это количество используемых членов последовательности (начальный индекс), а `order` — степень (порядок) ускорения.

### Anderson Acceleration
*   **CamelName**: `AndersonAccelerationAlgorithm`
*   **Описание**: Ускоряет итерации с фиксированной точкой, используя линейные комбинации предыдущих шагов.
*   **Входные параметры**:
    *   `n`: Индекс текущего члена (требуется `n >= 2` для активации ускорения).
    *   `order`: Не используется (зарезервировано).
*   **Дополнительные параметры**:
    *   `m` (K, по умолчанию 50): Глубина памяти (размер истории).
    *   `beta` (float_type, по умолчанию 1.0): Параметр смешивания $\in (0, 1]$.
    *   `safeguard` (float_type, по умолчанию 1e-12): Малое значение для численной устойчивости.
*   **Ограничения**: `beta` должно быть в диапазоне $(0, 1]$. Если `n < 2`, возвращается исходная частичная сумма $S_n$.

### Brezinski Theta
*   **CamelName**: `BrezinskiThetaAlgorithm`
*   **Описание**: Нелинейное преобразование последовательности, эффективное для ошибок, ведущих себя как суммы экспонент.
*   **Входные параметры**:
    *   `n`: Начальный индекс последовательности.
    *   `order`: Порядок преобразования (должен быть четным).
*   **Ограничения**: 
    *   `order % 2 == 0` (только четные порядки имеют математический смысл).
    *   Требуемый размер входных данных: `Sn.size() >= 1.5 * order + 1 + n`.
    *   При `n = 0` или нечетном `order` выбрасывается исключение.

### Chang-Wynn
*   **CamelName**: `ChangWynnAlgorithm`
*   **Описание**: Гибридный алгоритм, объединяющий эпсилон-алгоритм Винна с модификациями Чанга для устойчивости.
*   **Входные параметры**:
    *   `n`: Количество членов (автоматически округляется вниз до ближайшего четного).
    *   `order`: Не используется.
*   **Ограничения**: `n > 0`. Требуется наличие векторов частичных сумм (`Sn`) и самих членов ряда (`an`) размера не менее `n + 1`.

### Drummond D
*   **CamelName**: `DrummondDAlgorithm`
*   **Описание**: Эффективен для знакочередующихся рядов и специфического поведения остатка.
*   **Варианты**: `u`, `t`, `v`, `t_wave`, `v_wave`.
*   **Входные параметры**:
    *   `n`: Начальный индекс.
    *   `order`: Порядок трансформации.
*   **Дополнительные параметры**:
    *   `remainder_type` (shanks::remainders::remainder_type): Стратегия оценки остатка.
    *   `use_recurrent_formula` (bool, по умолчанию false): Использовать рекурсивную схему для устойчивости.
*   **Ограничения**: Размер `Sn` и `an` должен быть достаточным для выбранного варианта остатка (обычно `>= n + order + 1`).

### Ford-Sidi
*   **CamelName**: `FordSidi2Algorithm`, `FordSidi3Algorithm`
*   **Описание**: Эффективные методы экстраполяции, требующие меньше операций, чем E-алгоритм.
*   **Входные параметры**:
    *   `n`: Количество членов (начальный индекс).
    *   `order`: Не используется.
*   **Ограничения**: 
    *   `n > 0`. При `n = 0` выбрасывается `std::domain_error`.
    *   Для `FordSidi2`: требуется `Sn.size() >= n + 2`.

### J-Transformation
*   **CamelName**: `JTransformationAlgorithm`
*   **Описание**: Нелинейное преобразование для медленно сходящихся или расходящихся рядов.
*   **Входные параметры**:
    *   `n`: Начальный индекс.
    *   `order`: Порядок преобразования.
*   **Дополнительные параметры**:
    *   `max_order` (K, по умолчанию 30): Максимально допустимый порядок.
    *   `safeguard` (float_type, по умолчанию 1e-12): Порог устойчивости.
*   **Ограничения**: `0 <= order <= max_order` и `n >= order`. Требуется `Sn.size() >= n + order + 1`.

### Levin / Levin-Sidi
*   **Алгоритмы**: `LevinAlgorithm`, `LevinSidiSAlgorithm`
*   **Описание**: Преобразования для последовательностей с асимптотическими шаблонами остатков.
*   **Входные параметры**: `n` (индекс), `order` (степень).
*   **Дополнительные параметры**:
    *   `remainder_type` (shanks::remainders::remainder_type).
    *   `use_recurrent_formula` (bool, по умолчанию false).
    *   `beta` (float_type, по умолчанию 1.0): Должно быть $> 0$.
*   **Ограничения**: `n > 0`, `beta > 0`.

### Levin-Sidi M
*   **CamelName**: `LevinSidiMAlgorithm`
*   **Описание**: Специализированное преобразование для рядов с факториальной или линейной сходимостью.
*   **Входные параметры** (Внимание: роли параметров инвертированы!):
    *   `n`: **Порядок** преобразования.
    *   `order`: **Начальный индекс** последовательности.
*   **Дополнительные параметры**:
    *   `gamma` (float_type, по умолчанию 100.5): Должно быть $> 0$.
*   **Ограничения**: `gamma >= n + 1`. При нарушении выбрасывается `std::domain_error`.

### Lubkin W
*   **CamelName**: `LubkinWAlgorithm`
*   **Описание**: Эффективен для линейной и логарифмической сходимости.
*   **Входные параметры**: `n` (индекс), `order` (степень).
*   **Ограничения**: Требуется `Sn.size() >= n + 3 * order + 1`.

### Richardson
*   **CamelName**: `RichardsonAlgorithm`
*   **Описание**: Полиномиальная экстраполяция.
*   **Входные параметры**: `n` (количество членов), `order` (не используется).
*   **Ограничения**: `n > 0`.

### Shanks
*   **CamelName**: `ShanksAlgorithm`, `ShanksTransformAlternating`
*   **Описание**: Ускоряет последовательности, ведущие себя как суммы экспонент.
*   **Входные параметры**: `n` (индекс), `order` (степень).
*   **Ограничения**:
    *   `n >= order` и `n > 0`.
    *   `ShanksAlgorithm` требует `Sn.size() >= 2 * order + n + 1`.
    *   `ShanksTransformAlternating` требует `Sn.size() >= order + n + 1`.

### Weniger
*   **CamelName**: `WenigerAlgorithm`
*   **Описание**: Преобразование с использованием факториальных рядов.
*   **Входные параметры**: `n` (индекс), `order` (количество членов в сумме).
*   **Ограничения**: `order >= 1`.

### Wynn Epsilon
*   **CamelName**: `WynnEpsilon1Algorithm`, `WynnEpsilon2Algorithm`, `WynnEpsilon3Algorithm`
*   **Описание**: Классический эпсилон-алгоритм.
*   **Входные параметры**: `n` (индекс), `order` (степень).
*   **Ограничения**:
    *   `n > 0`. При `n = 0` выбрасывается исключение.
    *   Требуемый размер `Sn`: `n + 2 * order + 1` (варианты 1 и 2) или `n + order + 1` (вариант 3).

### Wynn Rho
*   **CamelName**: `WynnRhoAlgorithm`
*   **Описание**: Эффективен для логарифмически сходящихся последовательностей.
*   **Входные параметры**:
    *   `n`: Начальный индекс.
    *   `order`: Порядок преобразования (должен быть четным).
*   **Дополнительные параметры**:
    *   `numerator_type`: `rho`, `generalized`, `gamma_rho`.
    *   `gamma` (по умолчанию -1.0), `rho` (по умолчанию 1.0).
*   **Ограничения**: `order % 2 == 0`.

```
