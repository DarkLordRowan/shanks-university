## Исправленные дефекты

1. `arcsinh_x`: рекурсия давала x/sqrt(1+x²), а не asinh(x).
   Восстановлен множитель (2n-1)/(2n+1). Источник: https://dlmf.nist.gov/4.38#E1.
2. `sqrt_1plusx_min_1_min_x_div_2`: знаменатель отношения соседних членов
   должен быть 2n+4, а не 2n+2. Источник: биномиальный ряд, https://dlmf.nist.gov/4.6.
3. `euler_mascheroni`: члены не умножались на x, хотя get_sum возвращал x*gamma.
   Проверена конечная телескопическая сумма x*(H_N-log(N+1)).
   Источник: https://dlmf.nist.gov/5.2#E3.
4. `two_ln2`: произведения индексов вычислялись в unsigned до преобразования
   в вещественный тип, что давало переполнение уже на умеренных n.
   Теперь сначала выполняется преобразование. Проверены n=1000 и точная
   конечная сумма через гармонические числа. Разложение на простые дроби приведено в коде.
5. `ten_minus_x`: формула 10-x относится к интервалу 5<x<15, а конструктор
   принимал любые конечные x. За его пределами ряд задаёт периодическое продолжение;
   на концах — полусумму скачка. Ограничена область для заявленной ветви.
   Источник: https://dlmf.nist.gov/1.8.
6. `wynn_epsilon_1`: запрещал корректный n=0, неверно выравнивал столбцы,
   обращался к Sn[0] до проверки размера. Переписана рекурсия с явным
   хранением двух предыдущих столбцов; сингулярность даёт исключение.
   Источник: https://dlmf.nist.gov/3.9#E11.
7. `richardson`: на нечётных n возвращал предыдущую строку после swap.
   Теперь результат всегда берётся из e[0]. Проверены обе чётности на точном ядре 4^(-n).
8. `shanks`: обращался к Sn[0] до проверки пустого ввода.

В математических и межъязыковых тестах проверяются 97 рядов, частичные суммы и индексы, два экспоненциальных
остатка, совпадение Шенкса с Винном, нулевой порядок, исключения и вырождение.
Винн дополнительно проверен на complex<double> и MPFR с точностью 200 бит.
Это не является сертификацией всех типов и вариантов ускорителей библиотеки.

## Воспроизведение

Нужны CMake, C++20, Eigen3, GMP, MPFR и GSL. Из корня shanks-university:

```sh
cmake -S backend/core -B /tmp/shanks-build -DBUILD_TESTING=ON
cmake --build /tmp/shanks-build --target mathematical_regressions catalogue_probe -j2
ctest --test-dir /tmp/shanks-build --output-on-failure
```

Проверенный запуск GCC 13.3: CTest 1/1 прошёл. Для сопоставления с Python:
см. `arbac/docs/mathematical-verification.md` в соседнем репозитории.

## Сплошной численный пробник каталога

```sh
python tools/probe_cpp_catalogue.py /tmp/shanks-build/catalogue_probe \
  --output /tmp/catalogue-sample.json
```

Каждый из 109 рядов запускается отдельным процессом с ограничением времени.
Сохраняются аргумент, заявленная сумма, частичная сумма, первые члены и остаток.
Снимок запуска: `catalogue-sample.json`. При N=256 у 80 рядов остаток меньше
1e-6, у 29 требуется разбор. Ошибок процессов в этом запуске нет.

Это проверка согласованности реализации с её же get_sum на одной точке,
а не независимое доказательство формулы. Ряды Фурье, медленные ряды и
последовательности Румпа могут давать заметный остаток без ошибки в формуле.
`natural_series` содержит расходящийся ряд и заявляет регуляризованное -1/12;
это не обычная сумма. `integral1` — конечная квадратура, которая пропускает
интервал около логарифмической особенности; её остаток нельзя трактовать
как ошибку ускорителя. Эти случаи не перенесены как проверенные обычные ряды.

Полная таблица статуса переноса — в `catalogue-coverage.md`.
Оставшиеся ряды, специальные последовательности и варианты алгоритмов требуют
индивидуальной проверки по литературе и независимых тестов перед переносом в arbacc.


## Продолжение: второй этап

Дополнительно перенесены в Python 19 позиций каталога: всего 48 из 109 имеют
проверенные Python-аналоги (ещё один Python-ряд — базовый log1p).
Осталась 61 позиция каталога. Добавлены независимые эталоны для новых рядов,
рациональная интерполяция для rho и точная рациональная арифметика для theta.

Новые исправления C++:

- `half_asin_two_x`: восстановлен квадрат (2n-1) в отношении соседних членов.
  Контроль x⁵ даёт 6/5, а не 2/5. Источник: https://dlmf.nist.gov/4.24#E1.
- `m_fact_1mx_mp1_inverse`: факториал считался в типе индекса, поэтому 13!
  переполнял unsigned32. Теперь произведение вычисляется в типе значения;
  в рекурсии m+n также складываются после преобразования.
- `wynn_rho` и `rho_transform`: стандартный числитель должен использовать
  узлы x_n=n+1, а не члены ряда an. Восстановлено правильное сужение столбцов,
  разрешена работа с последовательностью без an, исправлен расход входа,
  добавлены проверки пустого ввода и нечётного столбца.
  Источник: Weniger (1989), (6.2-2), https://arxiv.org/pdf/math/0306302.
- `drummond_d` для u-остатка: явно задан beta=1 вместо неявного нуля,
  который создавал деление на ноль в первом окне. Проверены прямая и
  рекурсивная формы для всех пяти оценок остатка.
- `brezinski_theta`: проверка размера теперь предшествует обращению к Sn[0].

Нумерация порядков: C++ rho/theta принимает чётный столбец 2k; Python принимает k,
то есть число пар преобразований. Python rho реализует классическую сетку x_n=n+1.
Параметризованные числители C++ rho ещё не сертифицированы; для gamma=-1
проверено совпадение обобщённого числителя с классическим.

Специальные функции Python используют backend-константы pi и gamma, а не
константы double. Наличие некоторых double-констант в исходных C++-рядах
остаётся ограничением их произвольной точности; межъязыковые тесты этих рядов
проверяют double-точность. Идентификатор `erf` в старом каталоге означает
интеграл exp(-t²), то есть sqrt(pi)*erf(x)/2, что сохранено при переносе.


## Продолжение: третий этап

Текущий статус: 98 из 109 позиций имеют проверенные Python-аналоги.
Подробный отчёт — в `arbac/docs/continuation-03.md` соседнего репозитория.
В Python 99 синтетических рядов (с базовым log1p) и 11 ускорителей;
1796 тестов проходят. Межъязыковые проверки включают 776 коэффициентов
97 рядов и 315 значений ускорителей.

Новые исправления C++: приведение pi к int в three_minus_pi; ограниченная
арифметика индексов в 18 рациональных генераторах; неправильная частота
косинусных гармоник кусочно-линейного ряда; особенность log(sin(x)/x) при нуле;
валидация вещественных аргументов Бесселя и нижней gamma; смещение beta и
ошибочные рекурсии Левина/Sidi-S; нехватка an в Weniger; виртуальная сигнатура
и расход данных Overholt; чтение пустого ввода W.

Рекурсивные Левин/Sidi-S вычисляют конечные разности тех же фиксированных
весов, что и прямые формы, согласно Weniger (7.1-7), (8.2-7).
Общий `levin_weights.hpp` устраняет дублирование ошибочных формул.
Проверен порядок 40 на MPFR (200 бит) и индексы n=1000000 рациональных рядов.
Источники: https://arxiv.org/pdf/math/0306302 и https://arxiv.org/pdf/math/0005209.

Оставшиеся 11 позиций требуют особой трактовки: 7 последовательностей Румпа,
расходящийся natural_series, квадратура integral1 и два ряда с восьмизначными
приближениями в get_sum. Они по-прежнему имеют статус pending.

Основной target `shanks` также успешно собран в дополнение к CTest-бинарникам.
Его интерактивное меню автоматически не запускалось.

В C++ убраны неверные эталоны Румпа №1/2/4 и эталоны возмущённых начальных данных.
