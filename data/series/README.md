# Папка Series

Этот каталог содержит файлы, представляющие различные математические ряды в формате JSON.
Каждый файл содержит данные о соответствующем ряде, включая:
1. Идентификатор
2. Название
3. Формулу
4. Документ.

## Структура папки

В папке находятся следующие файлы:

- Каждый файл с расширением `.json` представляет собой описание отдельного ряда.
- Алгоритмы именуются по принципу: `<имя_ряда>_series.json`.

Пример структуры одного файла ряда:

```json
{
  "id": "<идентификатор_раздела_из_документа>",
  "num": "<порядковый_номер>",
  "title": "<короткое название функции в LaTeX>",
  "formula": "<основной ряд в LaTeX>",
  "x_from": "<левый предел области сходимости>",
  "x_to": "<правый предел области сходимости>",
  "speed": "<скорость: logarithmic | linear | quadratic | cubic | hyperlinear | superexponential>",
  "document": "<имя файла .docx>"
}
```
