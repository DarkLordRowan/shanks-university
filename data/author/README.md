# Папка Authors

Этот каталог содержит файлы, представляющие информацию о различных авторах в формате JSON.
Каждый файл содержит данные о соответствующем авторе, включая:
1. Идентификатор
2. Имя
3. Ссылку на профиль (если доступна)

## Структура папки

В папке находятся следующие файлы:

- Каждый файл с расширением `.json` представляет собой описание отдельного автора.
- Авторы именуются по принципу: `<имя_автора_id>.json`.

Пример структуры одного файла автора:

```json
{
    "id": "",
    "name": "",
    "url": ""
}
```
